# FlowTax

Прототип сервиса для налогового вычета. Человек собирает расходы и документы, а FlowTax считает, сколько вернётся, и готовит сводку для декларации 3-НДФЛ. Это мой дизайн-проект из портфолио, перенесённый в код.

Посмотреть: https://alina170522.github.io/TaxFlow/

## Что сейчас работает

Прототип в разработке. Пройти от начала до конца пока можно только сценарий оформления вычета: на главной нажмите «Подготовить декларацию».

1. Вид вычета, год и за кого платили.
2. Документы. За 2025 год справка и договор уже подставлены из демо-данных, за другие годы их нужно загрузить и ввести сумму из справки. Файлы остаются в браузере и никуда не отправляются.
3. Доход за год: ссылка на личный кабинет ФНС или ввод вручную.
4. Проверка и сумма возврата, после неё сводка для декларации.

Разделы «Расходы», «Справки», «Документы», уведомления и профиль ещё в разработке, ссылки на них ведут на экран-заглушку. Цифры на главной (расходы по категориям, справки) взяты из демо-данных.

ИИ-помощник пока отвечает по базе правил с ключевыми словами, нейросеть к нему не подключена. Расчёт примерный и не заменяет консультацию налогового специалиста.

## Как сделано

Идея, макет и UI-kit в Figma мои. Код собран с помощью Claude: я ставила задачи и принимала продуктовые решения, Claude писал код. Цвета, шрифты и иконки взяты из макета, переменные в коде названы так же, как в Figma.

Стек: Vue 3, Vite, Pinia, Vue Router, Less.

## Запуск

```bash
npm ci
npm run dev           # локальный сервер
npm run build         # сборка в dist/ для GitHub Pages
npm run build:single  # один HTML-файл в dist-single/
```

Сайт на GitHub Pages собирается автоматически при каждом пуше в ветку main (`.github/workflows/deploy.yml`).
