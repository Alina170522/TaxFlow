# FlowTax — интерфейс сервиса для налогового вычета

Кодовая версия моего дизайн-проекта FlowTax: личный кабинет, где можно отслеживать расходы на медицину, образование, спорт и недвижимость и получать справки для налогового вычета.

> **Статус:** прототип в разработке. Сверстан каркас интерфейса, логика и данные пока не подключены.


## Что уже есть
- Каркас страницы: боковое меню (`Sidebar`), шапка (`Header`), основная область (`Main`)
- Блоки: общая сумма и справки (`Summary`), категории организаций (`Categories`), быстрый доступ и быстрые действия (`FastAccess`, `FastAction`)
- Компонентный подход, у каждого блока своя папка
